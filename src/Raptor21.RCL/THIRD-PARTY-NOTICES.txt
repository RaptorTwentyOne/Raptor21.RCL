Blazor-ApexCharts
-------------------------------------------------------------------------------

Applies to        : Raptor21.RCL/Charts/Models and Raptor21.RCL/Charts/Serialization

Source repository : https://github.com/apexcharts/Blazor-ApexCharts
Ported from       : src/Blazor-ApexCharts/Models/ and src/Blazor-ApexCharts/Internal/
License           : MIT

What was taken: the C# chart-option model (the typed representation of the ApexCharts.js option
surface) and the System.Text.Json converters that serialize it. The Blazor components, the
JavaScript interop layer, the chart service, and the data-binding/data-point layer were not taken.

What was changed: namespaces (ApexCharts -> Raptor21.RCL.Charts.Models, ApexCharts.Internal ->
Raptor21.RCL.Charts.Serialization), the converters were made public, members that depended on
Blazor or JS interop were removed, and the TItem type parameter was dropped because the
data-binding layer it named was not ported. The option properties, their types, and their
documentation comments are otherwise unchanged, so the upstream ApexCharts documentation applies
to them directly.

Rizzy
-------------------------------------------------------------------------------

Source repository : https://github.com/JalexSocial/Rizzy
License           : MIT

Applies to        : Raptor21.RCL/Htmx (9 files), Raptor21.RCL/Composition (7 files),
                    Raptor21.RCL/Mvc (3 files), Raptor21.RCL/Rendering (2 files), and
                    Raptor21.RCL/Client/src/glue (antiforgery.ts, confirmation.ts, nonce.ts).
                    Each of those files carries an "Adapted from Rizzy" header naming the
                    upstream type it derives from.

What was taken: the htmx request/response abstraction (header names, swap styles, request and
response context), the composition layer that renders Razor components as full pages or htmx
fragments, the MVC controller/view-service surface, the component parameter builder, and the
client-side antiforgery, confirmation and nonce hooks.

What was changed: namespaces were changed to Raptor21.RCL.*, the source-generator-based
parameter and configuration machinery was dropped, the htmx configuration record was reduced to
the antiforgery block, and several behaviours were corrected (see each type's documentation).
